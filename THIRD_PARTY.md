# Сторонние компоненты / Third-party components

ReduxHub Visual Editor использует следующие компоненты. Спасибо их авторам.

| Компонент | Автор | Лицензия | Где |
|---|---|---|---|
| [Dear ImGui](https://github.com/ocornut/imgui) 1.92 | Omar Cornut | MIT | интерфейс редактора |
| [MinHook](https://github.com/TsudaKageyu/minhook) | Tsuda Kageyu | BSD 2-Clause | перехват отрисовки игры |
| [CodeWalker.Core](https://github.com/dexyfex/CodeWalker) | dexyfex | MIT | чтение архивов игры |
| [RageLib / gta-toolkit](https://github.com/Cryma/gta-toolkit) | Neodymium | MIT | запись архивов игры |
| [SharpDX](https://github.com/sharpdx/SharpDX) | Alexandre Mutel | MIT | зависимость CodeWalker |
| [.NET](https://github.com/dotnet/runtime) 8 | .NET Foundation | MIT | лаунчер |
| [Inter](https://rsms.me/inter/) | Rasmus Andersson | SIL Open Font License 1.1 | шрифт |
| [Phosphor Icons](https://phosphoricons.com/) | Phosphor Icons | MIT | иконки |

**Не входит в сборку:** [ScriptHookV](http://www.dev-c.com/gtav/scripthookv/) (Alexander Blade) — его лицензия запрещает распространение, поэтому лаунчер скачивает его с официального сайта автора на компьютер пользователя.

Grand Theft Auto V и связанные материалы принадлежат Take-Two Interactive / Rockstar Games. Проект не связан с ними и не одобрен ими.
